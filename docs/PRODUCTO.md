# Producto – PasajeYa

## Visión
Permitir a los pasajeros comprar pasajes de bus en línea de forma rápida y segura.

## Usuario
Pasajero que compra pasajes de bus.

## Alcance
**Incluye:** búsqueda de viajes, selección y reserva de asiento, pago simulado, boleto, reportes.
**No incluye:** inicio de sesión, panel de administración, pagos reales.

## Flujo del usuario
Buscar viaje → Elegir asiento → Reservar → Pagar → Recibir boleto
